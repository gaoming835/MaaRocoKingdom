# 月牙雪熊检测模型

将 YOLO11n 导出的单类别、静态 640×640 输入 ONNX 模型命名为
`sprite.onnx` 并放在本目录。

`sprite` 类别当前只表示月牙雪熊，不表示全部野外精灵。其他精灵必须作为
负样本，不应触发投球。2026-07-31 按用户决定安装了新旧数据联合候选模型，
作为月牙雪熊原型使用。本目录中的 `sprite.onnx` 不设置检测框高度门槛；
达到运行置信度阈值的直接 YOLO 检测均可进入自动瞄准。

本次安装覆盖了原跨设备验收门槛，不代表该门槛已经通过。运行阈值 `0.40`
的冻结测试 precision 为 96.75%、recall 为 76.94%，困难负样本误检为 2；
尚未执行实机 HID 投球验收。

该模型是“自动瞄准投球”的必需运行资源。缺少模型时任务会直接拒绝启动，
不会连接 AutoFlower、聚焦窗口、扫描或发送 HID 输入。训练流程见
`docs/zh_cn/develop/auto_aim_throw.md`。
